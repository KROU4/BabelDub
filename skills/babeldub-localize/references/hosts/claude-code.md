# Хост: Claude Code

Читай один раз в начале работы, если ты работаешь в Claude Code (CLI, desktop или IDE). Здесь — как действия скилла превращаются в инструменты Claude Code.

## Установка

- В сессии: `/plugin marketplace add KROU4/BabelDub`, затем `/plugin install babeldub@babeldub`.
- Из шелла: `claude plugin install babeldub --marketplace KROU4/BabelDub` (Claude Code 2.1.292 и новее).
- Разработка: `claude --plugin-dir <папка репозитория BabelDub>`.

Плагин не ставит Python-зависимости сам. CLI `babeldub` ставит скилл `babeldub-doctor` из папки плагина: `${CLAUDE_PLUGIN_ROOT}/runtime`. Переменная `${CLAUDE_PLUGIN_ROOT}` подставляется в текст скилла при загрузке, но в окружении Bash её нет. Поэтому команду с этим путём копируй из текста скилла, а не ссылайся на `$CLAUDE_PLUGIN_ROOT` в шелле.

## Действие → инструмент

| Действие в скилле | Claude Code |
|---|---|
| запустить команду `babeldub …` | Bash (на Windows подходит и PowerShell); одна команда на вызов; JSON читай из stdout |
| долгая стадия (`synth`, `qa`, `setup`, `extract` большой игры) | чанками (`--chars`, `--limit`) или Bash с `run_in_background`; дождись уведомления и проверь `babeldub status` |
| прочитать раздел отчёта | Read с `offset`/`limit`; файлы проекта целиком не читать |
| записать файл агента (`*.agent.jsonl`, `*.out.jsonl`, `style_bible.md`) | Write |
| задать вопрос пользователю (только 2 вопроса) | AskUserQuestion из главной сессии, 2–4 варианта |
| делегировать роль | Agent (субагент `babeldub-<роль>`) |
| параллельные переводчики | несколько вызовов Agent в одном сообщении, не больше 4 одновременно |

## Субагенты

- Определения лежат в `claude/agents/babeldub-<роль>.md` плагина и генерируются из `skills/babeldub-localize/references/roles/*.md`. В сессии они видны с префиксом плагина: `babeldub:babeldub-scout`, `babeldub:babeldub-translator` и т. д. Явный вызов: `@agent-babeldub:babeldub-translator`.
- Субагент не видит историю главной сессии. В сообщении делегирования передай всё нужное: папку проекта или slug, стадию, для переводчика — путь к его пакету `translate/batches/<bid>.in.jsonl`, для qa — что вернул `babeldub qa`.
- Субагенты не умеют AskUserQuestion. Вопросы задаёт только главная сессия; субагенты возвращают `human_pending`.
- Субагент отвечает одной JSON-сводкой. Не проси его пересказывать данные: подробности лежат в файлах проекта.
- Если субагенты недоступны (например, плагин загружен только как скилл), выполни роль сам по её файлу.

Цикл перевода в Claude Code:

1. Возьми до 4 разных `bid` из `batches[]` вывода `babeldub batch make` (если список обрезан — по именам файлов `translate/batches/<bid>.in.jsonl`, у которых ещё нет `.out.jsonl`). `batch next` всегда отдаёт первый незакрытый пакет, поэтому для раздачи нескольких пакетов он не подходит.
2. В одном сообщении запусти по субагенту `babeldub-translator` на каждый пакет; передай путь `translate/batches/<bid>.in.jsonl` в папке проекта.
3. По их сводкам проверь `merged` и `errors`, затем возьми следующие пакеты. Когда `batch next` вернёт `done: true`, перевод закончен.

## Хуки плагина

Хуки срабатывают во всех сессиях пользователя, поэтому они узкие и быстрые. Работе они только помогают: всё критичное делает CLI.

| Событие | Что делает | Что значит для тебя |
|---|---|---|
| `PreToolUse` (Write, Edit, Bash, PowerShell …) | блокирует запись в зарегистрированную папку игры мимо `babeldub install`, `uninstall`, `reapply` | если хук заблокировал действие, не обходи его: значит, ты пытался писать в папку игры |
| `SessionStart` (startup, resume, compact) | при активном проекте печатает 5–10 строк: игра, язык, стадия, следующий шаг | после сжатия контекста продолжай с указанного шага, сверившись с `babeldub status` |

## Команды

| Команда | Что делает |
|---|---|
| `/babeldub:localize <путь к игре> [язык]` | запускает скилл `babeldub-localize` с аргументами |
| `/babeldub:rollback [игра]` | откат: `babeldub uninstall` для проекта игры |
| `/babeldub:babeldub-<скилл>` | прямой вызов скилла, например `/babeldub:babeldub-doctor` |

## Особенности

- Тайм-аут одного вызова Bash ограничен (до 10 минут). Синтез сотен реплик дели на чанки или запускай в фоне.
- На Windows подставленные пути `${CLAUDE_PLUGIN_ROOT}` идут с прямыми слэшами; это нормально.
- Workflow-скрипты Claude Code (веер переводчиков) — только с явного согласия пользователя; по умолчанию используй цикл `batch next` → субагенты.
