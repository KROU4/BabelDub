# Неполадки и что с ними делать

Читай этот файл при кодах 1 и 4, при нехватке памяти GPU, странных метриках QA и проблемах установки. Каждый раздел: признак → причина → действие. Если признака нет в списке, смотри последний лог стадии в `logs/` проекта (по разделам, не целиком) и поле `where` в JSON.

## 1. CLI и окружение

| Признак | Причина | Действие |
|---|---|---|
| `babeldub: command not found` / «не является командой» | CLI не установлен или каталог инструментов uv не в `PATH` | скилл `babeldub-doctor`: `skills/babeldub-doctor/scripts/bootstrap.py`; если `on_path` = false, вызывай CLI по полному пути из поля `exe` или выполни `uv tool update-shell` и открой новый терминал |
| версия `babeldub --version` ≠ `metadata.babeldub-cli` | стоит старая или чужая сборка | `bootstrap.py --force` |
| `doctor` код 3, `todo[]` не пуст; `synth`/`qa`/`cast` код 4 | нет venv движка или весов | `babeldub setup --dry-run` → `babeldub setup` |
| `doctor` код 4, `missing[]`: `ffmpeg`, `ffprobe`, `uv` | обязательные утилиты ставит пользователь | команды — в поле `install{}` вывода `doctor` (Windows: `winget install Gyan.FFmpeg`; Linux: `sudo apt install ffmpeg`); затем новый терминал и `babeldub doctor` |
| `extract` код 4, нет `vgmstream-cli` | декодер не скачан | `babeldub setup --tools` |
| нет `rubberband` (`optional_missing[]`) | утилита необязательна (лицензия GPL, не поставляется) | CLI растягивает звук через `ffmpeg atempo`; качество растяжения чуть ниже, это не ошибка. Поставить можно: Windows `winget install BreakfastQuay.RubberBand`, Linux `sudo apt install rubberband-cli` |
| `setup` код 3, `blocked[]` | нет uv/git, некоммерческая лицензия без согласия, нет `uvx` и `huggingface_hub` | причина — в файле плана (`plan`); NC-модели не включать без явной просьбы пользователя |
| `setup` код 4 «not enough disk space» | не хватает места под веса и venv | освободить место или перенести `BABELDUB_HOME` до установки |
| `doctor` не видит GPU | нет драйвера NVIDIA или `nvidia-smi` | работа возможна на CPU, но синтез займёт часы; предупреди пользователя в отчёте |
| не хватает места на диске | модели тира 8 ГБ занимают ~7–8 ГБ, каждый venv ~3 ГБ (оценка, не проверено), декодированные оригиналы тоже занимают место (у Low-Budget Repairs ~2,3 ч звука дали ~1,1 ГБ WAV) | задать `BABELDUB_HOME` на диск со свободным местом до `setup` и `init`; лишние попытки синтеза в `synth/raw` можно удалить только после завершения проекта |
| ошибки путей на Windows (слишком длинный путь) | `MAX_PATH` | короткий `BABELDUB_HOME`, например `D:\BabelDub` |

## 2. GPU и синтез

| Признак | Причина | Действие |
|---|---|---|
| `CUDA out of memory` | на 8 ГБ модели держатся по одной; часть памяти занимает рабочий стол Windows | не запускать `synth` и `qa` одновременно; закрыть другие GPU-приложения; повторить чанком поменьше (`--limit`); если не помогло — лёгкая модель: `babeldub models fetch Qwen3-TTS-12Hz-0.6B-Base`, `babeldub set tts.model=Qwen3-TTS-12Hz-0.6B-Base` и запись в отчёт |
| GPU занят (`gpu.lock`) | другая GPU-стадия ещё идёт | дождаться окончания (`babeldub status`); второй GPU-процесс не запускать |
| воркер падает на отдельных строках (`failed` > 0) | редкий текст, пустая строка, битый референс | повторить `synth` для них; при повторе той же ошибки — решение `skip` или `keep_original` через роль qa |
| очень медленно (`rtf` больше 1) | CPU-режим или слабая GPU | синтез чанками по персонажам; приоритет главным; предупредить о времени |
| голос «не того» персонажа | неверная атрибуция говорящего в `cast` | caster проверяет персонажа (`query --where char=<id>`), правит метки; затем `reref` по затронутым репликам |

## 3. Качество дубляжа

| Признак в метриках | Вероятная причина | Действие |
|---|---|---|
| низкое `qa.sim` относительно `qa.sim_ref` у многих реплик персонажа (причина `sim`) | шумные или эмоционально крайние оригиналы в роли промпта (`line`) | роль qa: `reref` (промпт — референс персонажа); если брак системный — роль voice: `babeldub set tts.ref_strategy=char` на время синтеза этого персонажа (`synth --chars <A>`), потом вернуть `auto` |
| смена пола или возраста голоса | референс с чужим голосом, кластер смешал персонажей | caster проверяет референсы и метки; затем `reref` |
| высокий `qa.cer` (неразборчиво, пропуски, «галлюцинации»; смотри `qa.asr_text`) | слишком длинный или сложный текст, редкие слова, латиница, числа цифрами | `regen` (другой seed, его CLI ставит сам); при повторе — `retranslate` с упрощением, числа словами, латиница по `pronounce` в глоссарии |
| `qa.ratio` выше `qa.max_duration_ratio` (причина `duration`), `over_length[]` из `post` | текст на целевом языке длиннее оригинала (русский обычно на 10–20 %) | CLI ставит `shorten` → `babeldub batch make --from-decisions` → переводчик сокращает |
| причины `qc_error`, `missing_file`, `no_dub_text` | сбой воркера QA, нет файла после `post`, нет перевода | `babeldub qa --ids <ids>`; `babeldub post --ids <ids>`; `retranslate` |
| слышен акцент языка оригинала | межъязыковое клонирование переносит акцент языка референса | известный риск: зафиксировать в отчёте; если в игре есть несколько языков озвучки, отметить это как идею для следующего прогона |
| интонация «не та» в коротких репликах | для коротких строк промпт — референс персонажа, а не сама реплика | норма для `char`; если реплика ≥ 1,6 с и с текстом, проверить, что `ref_strategy` не зафиксирован в `char` |
| пики, клиппинг (`peak_db` выше потолка) | громкий оригинал, крик | повтор `post`; при повторе — `regen` |

Агент звук не слышит: решения принимаются только по метрикам. Субъективное «звучит плохо» без метрик в отчёт не пиши.

## 4. Разведка и связывание

| Признак | Причина | Действие |
|---|---|---|
| `scan` не нашёл голосовых контейнеров | движок или формат не поддержан в v0.1 | скилл `babeldub-recon`, справочник движка; отчёт пользователю с ручным путём |
| `level` C или B | формат читается, но не собирается без внешнего инструмента | не пытаться собрать вручную; описать путь из справочника |
| зашифрованные контейнеры (ключ FMOD-банка, AES паков, HCA) | шифрование | в v0.1 автоматического пути нет; записать в отчёт |
| много `unlinked` после `link` | ключи субтитров не совпадают с именами аудио | scout смотрит выборку, ищет закономерность (префиксы, подпапки, регистр) и пишет гипотезу в отчёт; реплики без текста остаются оригиналом |
| в диалоговом контейнере SFX, музыка, видео | общий банк или звук видеороликов | они получают `kind` `sfx`/`music`/`unknown` и не озвучиваются; видео в v0.1 вне объёма |
| предупреждение про античит или онлайн | EAC, BattlEye, VAC | остановиться, сообщить, ничего не устанавливать |

## 5. Сборка и установка

| Признак | Причина | Действие |
|---|---|---|
| `build` код 2 «native rebuild is not supported» | у адаптера уровень B или C | путь из справочника `babeldub-recon`; ничего не писать в папку игры |
| `verify` нашёл `problems[]` | несовпадение числа записей, ошибка кодека | не устанавливать; пересобрать (`build --force`), при повторе — отчёт |
| `install` не может заменить файл | игра запущена или файл занят | закрыть игру и лаунчер, повторить `install` |
| в игре нет звука или тишина вместо реплик | игра не приняла кодек пересобранного контейнера (в запущенной игре не проверялось) | `babeldub uninstall`; `babeldub build --codec pcm16` → `verify` → `install`; сообщить результат |
| реплики обрезаются в игре | синхронный инструмент, таймлайн катсцены или режим, который обрывает звук | сократить такие реплики (`shorten`) до длины оригинала; отметить их в отчёте |
| озвучка пропала после обновления или проверки целостности в Steam | клиент вернул оригинальные файлы | `babeldub reapply`; если `changed[]` не пуст — `build` → `verify` → `install` |
| нужно вернуть всё как было | — | `babeldub uninstall` (сверка sha1 с бэкапом) |
